LanCarbon Guide

September 2, 2026

English¶

Welcome to LanCarbon, an offline desktop application for writing Notes, organizing structured Books and exporting publishable Jupyter Book 2 projects.

LanCarbon stores your writing locally. It does not require an account and does not automatically upload your content to the internet.

This guide has two purposes:

  1. Help new users understand LanCarbon and Jupyter Book.

  2. Provide reusable examples for testing each development phase.

Current development status¶

Phase 1 is complete.

Phase 1 includes:

  • Local Notes and automatic saving

  • Multiple Jupyter Books

  • Sections and child pages

  • Hierarchical table-of-contents organization

  • Page reordering

  • Book Settings and Page Properties

  • Stable Markdown export paths

  • MyST frontmatter generation

  • myst.yml generation

  • Jupyter Book 2 project export

  • Strict build and local preview verification

Future phases will add editing, preview, resource management, validation and publishing features. Each completed phase will add a new reference section to this guide.

中文¶

欢迎使用 LanCarbon。这是一款离线桌面写作软件，可以管理普通笔记、组织结构化 Book，并导出能够在线发布的 Jupyter Book 2 项目。

LanCarbon 将写作内容保存在本机，不要求登录账号，也不会自动把内容上传到互联网。

这本指南有两个用途：

  1. 帮助新用户理解 LanCarbon 和 Jupyter Book。

  2. 作为每个开发阶段的可复用验收示例。

当前开发状态¶

Phase 1 已完成。

Phase 1 包括：

  • 本地 Notes 和自动保存

  • 创建多个 Jupyter Book

  • Section 和 Child Page

  • 树形目录组织

  • 页面拖拽排序

  • Book Settings 和 Page Properties

  • 稳定的 Markdown 导出路径

  • MyST frontmatter 生成

  • myst.yml 生成

  • Jupyter Book 2 项目导出

  • 严格构建和本地预览验证

后续阶段将逐步增加编辑器、预览、资源管理、校验和发布功能。每完成一个阶段，这本指南都会新增对应的 Reference 章节。
