### Export from LanCarbon

1. Save the current page.
2. Select **Export** in the Book sidebar.
3. Choose an empty directory.
4. Confirm the success message.

LanCarbon intentionally refuses to export into a non-empty directory. It never overwrites existing files.

### Expected files

The exported directory should contain:

- `myst.yml`
- `README.md`
- `index.md`
- Markdown files corresponding to the remaining Book pages

The directory structure follows each page’s Export Path.

### Strict build

Open PowerShell in the exported directory and run:

    jupyter book build --html --strict

A successful strict build should finish without errors.

Warnings should still be reviewed. For example, a single-word author name may produce a MyST name-structure warning.

### Local preview

Run:

    jupyter book start

Keep PowerShell open while previewing the website.

Wait until the terminal displays an address such as:

    http://localhost:3000

Open that address in a browser.

The first run may need internet access to download the official Book Theme from MyST and GitHub.

### Phase 1 acceptance checklist

- The home page exports as `index.md`.
- Every visible page appears in the correct navigation order.
- Hidden pages are built but do not appear in navigation.
- Section and Child Page hierarchy is correct.
- Markdown content is preserved.
- Page metadata appears in frontmatter.
- `myst.yml` contains the Book metadata and TOC.
- Strict build completes successfully.
- The localhost website opens.
- The Book remains available after restarting LanCarbon.

### 从 LanCarbon 导出

1. 确认当前页面已经保存。
2. 在 Book 侧边栏点击 **Export**。
3. 选择一个空目录。
4. 确认软件显示导出成功。

LanCarbon 会主动拒绝非空目录，并且绝不会覆盖已有文件。

### 预期文件

导出目录应包含：

- `myst.yml`
- `README.md`
- `index.md`
- 与其他 Book 页面对应的 Markdown 文件

文件目录结构由每个页面的 Export Path 决定。

### 严格构建

在导出目录中打开 PowerShell，然后运行：

    jupyter book build --html --strict

严格构建成功时，命令应当正常结束并且没有 Error。

Warning 仍然值得检查。例如，只有一个单词的作者名称可能触发 MyST 姓名结构警告。

### 本地预览

运行：

    jupyter book start

预览网站期间不要关闭 PowerShell。

等待终端显示类似下面的地址：

    http://localhost:3000

然后在浏览器中打开该地址。

第一次运行可能需要联网，从 MyST 和 GitHub 下载官方 Book Theme。

### Phase 1 验收清单

- 首页导出为 `index.md`。
- 所有可见页面按照正确顺序出现在导航中。
- 隐藏页面参与构建，但不显示在导航中。
- Section 和 Child Page 的层级正确。
- Markdown 正文完整保留。
- 页面元数据正确写入 frontmatter。
- `myst.yml` 包含 Book 元数据和 TOC。
- 严格构建成功。
- localhost 网站可以打开。
- 重启 LanCarbon 后 Book 仍然存在。
