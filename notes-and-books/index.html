Notes and Books

September 2, 2026

Ordinary Notes¶

Notes are independent local documents.

Each Note supports:

  • A title

  • Markdown content

  • Tags

  • Search

  • Pinning

  • Automatic saving

  • Character and line statistics

Use Notes for ideas, drafts, temporary records and content that does not yet belong to a publication.

Jupyter Books¶

A Book organizes selected Notes into a publishable hierarchy.

Each Book contains:

  • One fixed home page

  • Sections

  • Child Pages

  • Book Settings

  • Page Properties

  • A hierarchical table of contents

A Note can belong to no more than one Book at a time.

Add to Book¶

Add to Book places an existing ordinary Note into a selected Book.

The title and Markdown body remain unchanged. LanCarbon creates Book-specific information such as the Export Path and Page Properties.

Remove from Book¶

Remove from Book removes the page from the Book hierarchy and returns its content to ordinary Notes.

Its title and Markdown content are preserved.

If the selected page has children, its child pages are also removed from the Book and returned to Notes.

Delete¶

Deleting an ordinary Note permanently removes that Note.

Deleting a Book page permanently removes the selected page and all of its child pages.

Deleting an entire Book permanently removes its home page and every page inside that Book.

Use Remove from Book when you want to preserve the content. Use Delete only when the content is no longer needed.

普通 Notes¶

Notes 是保存在本机的独立文档。

每篇 Note 支持：

  • 标题

  • Markdown 正文

  • 标签

  • 搜索

  • 置顶

  • 自动保存

  • 字符数和行数统计

Notes 适合记录灵感、草稿、临时内容，以及尚未决定是否加入正式出版项目的材料。

Jupyter Book¶

Book 会把选定的 Notes 组织成可以发布的树形结构。

每个 Book 包含：

  • 一个固定首页

  • Section

  • Child Page

  • Book Settings

  • Page Properties

  • 树形目录

同一篇 Note 同一时间最多只能属于一个 Book。

Add to Book¶

Add to Book 会把一篇普通 Note 加入选定的 Book。

原有标题和 Markdown 正文不会改变。LanCarbon 会为它增加 Book 专用信息，例如 Export Path 和 Page Properties。

Remove from Book¶

Remove from Book 会把页面从 Book 目录中移除，并将其内容退回普通 Notes。

页面标题和 Markdown 正文都会保留。

如果该页面包含子页面，子页面也会一起移出 Book 并返回 Notes。

Delete¶

删除普通 Note 会永久删除该笔记。

删除 Book 页面会永久删除选中的页面及其所有子页面。

删除整个 Book 会永久删除 Book 首页和其中的全部页面。

如果希望保留内容，应使用 Remove from Book。只有确定不再需要内容时才使用 Delete。
